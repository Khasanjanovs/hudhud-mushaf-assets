# hudhud-mushaf-assets

Ассеты мусхафа для приложения Hudhud Vird.

- `fonts/pN.woff2` — шрифт страницы N мадинского мусхафа (KFGQPC, 604 файла).
  Глифы совпадают с печатным изданием, поэтому набранная ими страница
  остаётся резкой на любом увеличении.
- `layout/N.json` — что на какой строке стоит на странице N: коды глифов,
  номера строк и заголовки сур.

Зачем свой репозиторий: раньше и шрифты, и разметка тянулись с чужих
серверов. Для Корана это слабое место — чужая авария или смена адресов
оставила бы читателей без текста. Здесь всё под нашим контролем.

Источники: шрифты — Комплекс имени короля Фахда (через QUL), разметка —
api.quran.com. Раздаётся через jsDelivr.
